# 🎲2048Craft
![](src/media/SS1.png)

# 🌎Language
English only

# 🏆How to Play
1. Execute the ``/2048craft`` command.
2. Right-click an empty slot.
3. Stack items of the same type.
4. Right-click the slot currently in use to clear its contents.
5. Repeat until the maximum stage is reached.
